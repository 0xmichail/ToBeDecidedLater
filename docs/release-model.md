# Release Model

This public repository is the reviewed release surface for the project.

Development, experimentation, brainstorming, failed ideas, private planning notes, and raw AI-assisted drafts may happen outside the public repository first.

Public releases contain only reviewed, cleaned, and intentional artifacts.

## Public release principles

Before something is moved into this repository, it should be checked for:

- public safety;
- licensing and attribution implications;
- third-party notices;
- consistency with the project scope;
- usefulness to an external reader;
- traceability where relevant.

## What this means

The public repository should not be read as a complete product roadmap or as a scratchpad.

It is a curated public snapshot of the work that is ready to be shared.
